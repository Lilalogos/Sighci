# Ландшафт тем HCI, SIGCHI

Интерактивная карта **297 лауреатов премий SIGCHI** (1998–2026). Это не географическая карта: люди стоят рядом по темам исследований.

Темы собраны из рабочей таблицы проекта и из Google Scholar (чипсы интересов и заголовки статей). Приложение — Vite + React.

[English README](README.md)

Сайт: [https://lilalogos.github.io/SIGHCI_5september/](https://lilalogos.github.io/SIGHCI_5september/)

Пуш в `main` собирает GitHub Pages через Actions (`Settings → Pages → GitHub Actions`).

## Запуск

```bash
npm install
npm run dev
```

Откройте [http://127.0.0.1:5173/](http://127.0.0.1:5173/). Переключатель **RU / EN** в шапке меняет интерфейс, названия классов, теги Scholar и заголовки работ.

```bash
npm run build
npm run preview
```

## Что можно делать

- Двигать и масштабировать карту; клик по человеку открывает карточку (университет, награды, теги Scholar, ссылки на работы, портрет).
- Фильтр **Академия** / **Корпорация**. У корпоративных учёных узлы-квадраты; умершие отмечены пунктирным ромбом.
- Клик по области на карте или по чипсине внизу включает тему. Повторный клик выключает. Можно держать несколько тем сразу. **Сбросить темы** снимает выбор.
- Поиск по имени, русской транскрипции, университету и теме.

## Данные

Исходная таблица (локально): `SIGCHI_HCI_UX_researchers_FULL.xlsx`.

Пересборка `src/data/people.json` после смены правил кластеров или кэша:

```bash
npm run data
```

Скрипт `scripts/build_data.py` склеивает таблицу с кэшем Google Scholar, назначает классы, раскладывает людей (TF–IDF + t-SNE) и при необходимости переводит заголовки статей на русский.

Кэши Scholar и переводов лежат в `data/` и не коммитятся.

## Стек

- Интерфейс: Vite, React, TypeScript
- Раскладка и кластеры: Python, pandas, scikit-learn
